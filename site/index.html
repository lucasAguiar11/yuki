Yuki is named after a tuxedo cat who sleeps through most of the day, which is also how an empty response looks in the app. It is a native console for macOS, written in Rust on GPUI, the framework behind Zed. The engine that sends, resolves and stores requests began in Voleeo, also MIT, and Yuki is a new app around it. All of it is MIT: no feature sits behind a paywall, and personal use of the official build is free. Requests are plain YAML, one folder per workspace, each folder its own git repository, so a collection gets reviewed like code. The official build isn't notarized by Apple yet, so the first launch needs one manual step. Read the source on GitHub.

Download the .dmg for Apple Silicon or Intel. It keeps itself up to date after that. Install
