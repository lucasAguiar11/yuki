# Security policy

Yuki stores API credentials (auth secrets, secret environment variables, OAuth tokens) and sends requests on your behalf, so security reports matter.

## Reporting a vulnerability

Report it privately through [GitHub private vulnerability reporting](https://github.com/lucasAguiar11/yuki/security/advisories/new), never in a public issue. Include the commit you tested, what an attacker gains and the steps to reproduce.

Reports are handled by the maintainer on a best-effort basis.

## Supported versions

Pre-release: only the latest `main` gets fixes.
